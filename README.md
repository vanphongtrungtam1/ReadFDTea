# VSTEP Reading – Food & Diet – Teacher | GitHub Pages

## Upload tất cả file ngang hàng, không tạo thư mục con

1. Giải nén file ZIP này. Tất cả file đều nằm cùng một cấp.
2. Mở repository GitHub dành riêng cho phiên bản này → **Add file → Upload files**.
3. Upload **7 file**: `index.html`, `style.css`, `app.js`, `content-data.js`, `logo-cfl.jpg`, `logo-35-years.jpg`, `README.md` → Commit changes.
4. Vào **Settings → Pages → Deploy from a branch**, chọn `main` và `/(root)`, rồi Save.
5. Trang bài học mở ngay từ `index.html`; không có trang Listening/Reading còn lại.

## Nội dung

- **Reading only** – chỉ chứa kỹ năng Reading; không chứa nội dung kỹ năng kia.
- **40 câu Reading gồm 4 passages, mỗi passage 10 câu**.
- 72 Vocabulary Warm-up MCQs, 18 câu trước mỗi Passage.
- Trắc nghiệm, Check, từ điển, font chữ, lưu tiến độ và Reset giữ nguyên từ bản Food & Diet trước.
- Highlight, đồng hồ 15 phút/passage và 10 dạng câu hỏi VSTEP Reading.
- Hiển thị Key, Evidence và Explanation để giảng viên chữa bài.

## Lưu ý

Trang được triển khai bằng các file tĩnh HTML/CSS/JS, không cần build. Bản học viên và bản giảng viên phải upload lên **hai repository khác nhau** nếu muốn có đường dẫn riêng. Tất cả file đều ngang hàng ở root. Đáp án trong JavaScript của bản học viên có thể bị đọc qua developer tools nên đây không phải hệ thống thi bảo mật; dữ liệu làm bài chỉ lưu trong trình duyệt.
